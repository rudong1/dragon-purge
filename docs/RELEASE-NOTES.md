白龙娘桌宠 v0.3.0：安静陪伴、位置锁定与一键找回。

- 人物右键的“设置”与托盘菜单新增安静陪伴：隐藏角色台词、暂停主动求摸摸，仍可手动互动和自然打盹。
- 新增锁定位置，防止误拖动，保留点击摸头与右键菜单；两项设置自动保存，重启后仍生效。
- 新增找回桌宠，即使已经隐藏或锁定，也能通过托盘将她带回主屏幕右下角。

- 直接右击人物，打开奶白 / 薄荷绿的龙娘主题菜单。
- 人物上常驻“更新”按钮，显示版本、检查结果、下载进度和重启安装。
- 支持坐姿晃腿、抱尾巴打盹、点击揉眼醒来、摸头后持续摇尾和坐姿换装。
- 保留桌面快捷方式、拖动、托盘、大小与置顶设置，以及固定可见的退出按钮。
- 发布前校验安装器与更新清单，所有文件上传完成后才公开发行。

安装包尚未配置代码签名证书；仍未在真实 Windows 桌面上人工验证安装与跨版本升级。
